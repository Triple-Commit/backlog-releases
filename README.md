# Backlog — instaladores

Só os instaladores do Backlog para Windows. O código é privado.

## Instalar
1. Baixe o `Backlog_X.Y.Z_x64-setup.exe` da [última versão](https://github.com/Triple-Commit/backlog-releases/releases/latest).
2. Abra. Se o Windows avisar ("o Windows protegeu o computador"): **Mais informações → Executar assim mesmo**.
3. Pronto. Depois disso o app se atualiza sozinho (Ajustes → Sobre).
